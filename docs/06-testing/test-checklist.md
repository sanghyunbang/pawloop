# 테스트 체크리스트

> Pawloop(포루프) MVP 수동 테스트 체크리스트 + 단위/위젯 테스트 도입 계획. 화면별 확인 항목, 지도·GPS·공공데이터 케이스, 회귀 체크를 한 곳에 모은다.

관련 문서: [빌드/실행](../05-build/mvp-scope.md) · [ERD](../03-database/erd.md) · [아키텍처](../02-architecture/system-overview.md)

---

## 0. 사용법 · 전제

- 대상: Flutter 앱(`app/`, 화면은 `lib/v2/` 하위). 현재는 자동화 테스트가 거의 없어 **수동 회귀**가 1차 방어선이다.
- 실행: 안드로이드 에뮬레이터 권장(네이버맵 SDK · **백엔드** 실호출). 지도가 흰 화면이면 `--dart-define` 의 `NAVER_MAP_CLIENT_ID` 와 `API_BASE_URL` 을 확인. 장소가 안 뜨면 **서버 쪽**을 본다 — `kto_call_budget` 의 `used` 와 `place_cell` 행 수(#40). 템플릿은 `app/dart-define.example.json`, 실행은 `flutter run --dart-define-from-file=dart-define.json`.
- 표기 규칙:
  - ✅ **정상 기대** — MVP에서 반드시 통과해야 하는 항목
  - 🟡 **더미/미구현 확인** — 지금은 하드코딩/더미가 "의도된" 동작(아래 [11. 알려진 더미](#11-알려진-더미미연동-오탐-방지)와 대조)
- 릴리스/큰 변경 전에는 최소 [9. 회귀 체크](#9-회귀-체크-릴리스큰-변경-전) 스모크를 돌린다.

주요 소스 기준(항목 근거):

## 4. 실시간 산책 트래킹 (`walk_tracking_screen.dart`)

> 실 GPS 다. 위치를 못 잡을 때만 서울숲 근처 더미 루프로 떨어지고, **그 경로는 저장되지 않는다**(손입력으로 넘어간다). 위치 판정이 끝나기 전에는 아무것도 그리지 않는다 — 그러지 않으면 가짜 점이 진짜 경로 앞에 붙는다(#145 실측).

| # | 확인 항목 | 기대 |
|---|---|---|
| T1 | 진입 즉시 시작 | ✅ onMapReady에서 자동 트래킹, "산책 기록 중" + 붉은 점(라이브) |
| T2 | 라이브 스탯(km/시간/페이스) | ✅ 매초 거리 누적, 시간 `mm:ss` 증가, 페이스 `m'ss"` 갱신 |
| T3 | 경로 폴리라인 | ✅ 이동에 따라 핑크 선이 이어짐, head 마커가 최신 점 추적 |
| T4 | 카메라 추적 | ✅ 최신 위치로 카메라 이동 |
| T5 | 일시정지 | ✅ 탭 시 타이머 정지, 라벨 "일시정지됨"·점 회색, 스탯 멈춤 |
| T6 | 재개 | ✅ 탭 시 다시 누적 |
| T7 | 종료 → 완료 시트 | ✅ 시간/거리/페이스 요약, "기록 저장하기" / "저장 안 함" |
| T8 | "기록 저장하기" | ✅ 작성 화면으로 이동하며 **초안(거리·시간·경로)을 넘긴다.** 거리가 실측값에서 시작한다(하드코딩 2.0 이 아니다) |
| T9 | "저장 안 함" | ✅ 시트·트래킹 닫고 이전 화면 복귀 |
| T10 | 상단 뒤로가기 | ✅ 타이머 취소 후 pop(백그라운드 타이머 잔존 없음) |
| T11 | 시작 직후(거리<0.01) 페이스 | ✅ `-'--"` 방어 표시(0 나눗셈 없음) |
| T12 | 트래킹 중 화면 나가기 | ✅ dispose에서 타이머 cancel(로그/setState after dispose 경고 없음) |

## 5. 통계 (`insight_screen.dart`)

> 데이터 소스: `GET /api/walks/stats/weekly`(이번 주 + 전체 기간) + 전송 대기 초안. 주 경계는 KST 이고 서버가 자른다.

| # | 확인 항목 | 기대 |
|---|---|---|
| S1 | 헤더 "산책 통계 / 우리 아이 활동 기록" | ✅ 표시 |
| S2 | 이번 주 요약 3셀(총 거리/횟수/평균) | ✅ 서버의 `weekKm` 합계 · **산책 건수**(날 수가 아니다) · 평균. 예전에는 0 이 아닌 요일을 세어 "횟수" 라고 불렀다 |
| S3 | 주간 막대그래프(월~일) | ✅ 7개 막대, 값 0인 요일(목) 빈 막대 |
| S4 | 오늘 강조 | ✅ 오늘(일, idx 6) 막대만 웜 그라데이션·라벨 강조 |
| S5 | 막대 탭 툴팁 | ✅ "N요일 / X.X km" 팝업 |
| S6 | Y축 눈금 | ✅ maxY 기준 4분할, 0 라벨 숨김 |
| S7 | 자주 가는 곳 top 3 | ❌ **항상 빈 상태.** `Walk` 에 장소 축이 없어 셀 근거가 없다(계약의 `topPlaces` 도 같다) |
| S8 | 데이터 전부 0인 경우(가정) | ✅ 평균 0 분기, 차트 maxY 1.0 폴백(크래시 없음) |

## 11. 알려진 더미/미연동 (오탐 방지)

리뷰/QA가 "버그"로 오인하기 쉬운, **현재는 의도된** 동작:

- 홈 날씨 카드 = 고정 문구
- 지도 중심 = 서울시청 고정(현재 위치 미도입)
- 병원/펫샵/산책로 = 더미 레이어("공공데이터 (더미)" 표기)
- 검색창 = 플레이스홀더(검색 미구현)
- 커뮤니티 반응/댓글 = 화면 로컬 상태(재진입 시 초기화)
- 산책 기록의 **사진 첨부** = 스낵바 안내(미구현). 기록 자체는 서버에 저장된다(#145)
- 통계의 **자주 가는 곳** = 항상 빈 상태. `Walk` 에 장소 축이 없다 — 더미가 아니라 **없는 것**이다
- 로그인/북마크 = 스낵바 안내(실기능 없음)
