# 애플 1.2 재심사용 화면 녹화 대본

애플이 이번에 보려는 것은 셋입니다(2026-10 반려 메일).

1. **로그인 전에** 약관(EULA)에 동의하는 장면
2. 남의 글을 **신고**하는 장면
3. 남을 **차단**하고, 그 사람 글이 **바로 사라지는** 장면

실기기(아이폰)로 찍어야 하고, 앱을 **켜는 것부터** 시작해야 합니다. 목표 길이 1분 30초 ~ 2분.

---

## 찍기 전 준비

### 1. 새 빌드 설치 (제가 합니다)

`2.0.0 (4)` — #781(로그인 체크칸) · #784(차단 버튼)가 들어간 빌드입니다. 아이폰을 맥에 꽂고 잠금을 풀어
주시면 깔아 드립니다. **지금 폰의 빌드 3 에는 둘 다 없습니다.**

### 2. "남" 역할을 할 계정으로 글을 두 개 써 둡니다

신고·차단 버튼은 **남의 글**에만 뜹니다. 녹화는 애플 계정으로 하니까, 다른 계정으로 쓴 글이 필요합니다.

> 로그인 화면 → 체크칸 체크 → `카카오로 시작하기` 또는 `Google로 시작하기` → 커뮤니티 탭 → `글쓰기`
> → 사진 붙여서 두 개 → 우상단 프로필 → `로그아웃`

**차단돼도 괜찮은 계정으로 쓴다(평소 쓰는 주 계정은 피한다).** 녹화에서 그 계정을 차단하게 되는데,
커뮤니티에는 아직 차단 목록·차단 해제 화면이 없어서 한 번 차단하면 앱에서 풀 길이 없습니다.

### 3. 앱을 지웠다가 다시 깝니다

그래야 로그인 화면의 체크칸이 **빈 채로** 나옵니다(한 번 체크하면 그 기기에 기억됩니다).

### 4. 방해금지 모드를 켭니다

## 녹화 순서

**화면 녹화를 먼저 켜고, 홈 화면에서 시작합니다.**

| # | 무엇을 | 애플이 보는 것 |
|:--|:--|:--|
| 1 | 홈 화면에서 **포루프 아이콘을 탭** | 앱을 켜는 것부터 |
| 2 | 소개 3장 → `시작하기`, 권한 안내 → `확인했어요` | |
| 3 | 로그인 화면이 나오면 **체크칸을 누르지 말고** `Apple로 계속하기` 를 한 번 탭 → 아래에 "이용약관과 개인정보처리방침에 동의하면 시작할 수 있어요" 가 뜨는 것을 보여 줌 | **동의 없이는 로그인이 안 된다** |
| 4 | 체크칸 옆 **`이용약관`** 글자를 탭 → 약관이 열리면 천천히 내려서 **제6조의 굵은 문장**("회사는 불쾌한 콘텐츠와 다른 이용자를 괴롭히는 행위를 일절 허용하지 않습니다…")이 화면에 2초쯤 보이게 → 뒤로 | 약관에 무관용이 적혀 있다 |
| 5 | **체크칸을 탭**(동그라미가 주황으로) → `Apple로 계속하기` | 동의한 뒤에 로그인 |
| 6 | (처음이면) 동의 화면 → `전체 동의` → `동의하고 시작하기`, 반려견 등록은 `나중에 할래요` | |
| 7 | **커뮤니티 탭** → 2번에서 써 둔 남의 글이 목록에 보이는 것을 1초 → 그 글을 탭 | |
| 8 | 오른쪽 위 **`신고`** → 사유 하나 고르기 → 보내기 → "신고를 접수했어요". 시트 아래의 **가리기 칸은 체크하지 않습니다** — 차단은 다음 단계에서 따로 보여 줍니다 | **신고** |
| 9 | 같은 화면 오른쪽 위 **`차단`** → 확인 창의 문장("이 사람의 글과 댓글이 내 화면에서 사라지고, 운영자에게 알림이 갑니다…")이 보이게 1초 → `차단하기` | **차단 + 운영자 알림** |
| 10 | 화면이 "차단한 사용자의 글이에요" 로 바뀌는 것 → **뒤로** → 목록에서 그 사람 글 **두 개가 다 없어진 것**을 2초 보여 줌 | **바로 사라진다** |
| 11 | 녹화 끝 | |
