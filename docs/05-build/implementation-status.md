# 구현 현황 (Implementation Status)

> Pawloop(포루프) 앱과 서버의 화면·기능별 실제 상태. **소스 오브 트루스는 코드**(`app/lib/v2/` · `backend/src/main/java/`)이고, 이 문서는 그것을 읽고 정리한 것이다.

- **기준 시점**: 2026-09-15
- **엔트리**: `app/lib/main.dart` → go_router(`app/lib/app/app_router.dart`) → `/home` = `v2/screens/main_shell.dart`(`MainShell`)
- **네비**: 플로팅 글래스 알약 **다섯 탭 — 홈 / 지도 / 일정 / 커뮤니티 / 채팅**. 다섯 칸이 같은 폭이고 **산책 FAB 은 없다** — 산책은 홈의 "산책 시작" 이 연다(#446, 2026-09-14 결정). 통계(`insight_screen`)는 탭이 아니라 `me_screen`·`today_screen` 둘에서 진입한다
- **상태 표기**: `서버`(앱이 서버와 주고받음) · `기기`(기기 안에만 남음) · `더미`(하드코딩) · `미구현`

## 3. 기능·도메인 상태

### 3.1 산책
| 기능 | 상태 | 비고 |
| --- | --- | --- |
| 실시간 GPS 트래킹 | ✅ | geolocator 스트림 + `walk.path` LINESTRING(#145). 위치 판정 전에는 아무것도 안 그린다 |
| 기록 저장 | ✅ | `POST /api/walks`. 못 보내면 초안 큐가 들고 있다가 다시 보낸다 |
| 산책 사진 | ✅ | 한 손 기록 줄의 카메라 → 문서 폴더에 두고, `WalkSync` 가 `WALK_IMAGE` 로 올린 뒤 `mediaIds` 로 붙인다(#450) |
| 통계·차트 | ✅ | `GET /api/walks/stats/weekly` — 이번 주 + 전체 기간 |
| 자주 가는 곳 | ✅ | `WalkStats.topPlaces` 상위 다섯(#338). **카탈로그에서 고른 장소만** 센다 — 손으로 적은 이름은 그 기록에만 남는다 |
| AI 주간 요약 | ✅ | 서버가 주 3회까지 만들어 캐시하고(`weekly_insight`) 앱은 카드로 그린다. 👍/👎 · 만드는 중이면 한 줄 안내(#486) |
| 코스 | ✅ | 내 산책을 코스로 남기고(양 끝 100m 를 서버가 자른다) 글에 붙인다(#339) |

## 4. 아키텍처 실측

| 항목 | 실제 |
| --- | --- |
| 구조 | `main.dart` → go_router `/home` → `MainShell`. 화면 `v2/screens/`, 도메인 `v2/domain/`(순수 규칙), 데이터 `v2/data/`(저장소·정책), 위젯 `v2/widgets/`, 테마 `v2/theme/` |
| 상태관리 | `ValueNotifier` + `ValueListenableBuilder`, 화면 안은 `setState` |
| 라우팅 | 탭은 `RootTab.index`(전역 `ValueNotifier`), 상세는 `Navigator.push` |
| 네트워크 | `http` + `AuthedClient`(401 자동 갱신 · 단일 비행). 외부 직접 호출 **0종** |
| 설정 | 컴파일 타임 `--dart-define` 단독. 단일 진입점 `core/config/env.dart` |
