# Pawloop(포루프) 수익화 전략

> 무료 성장 루프(산책·케어·커뮤니티)는 끝까지 무료로 지키고, **① 지역 광고 → ② 제휴 커머스/보험 → ③ 기능 구독(Pawloop+)** 순서로 운영부담이 낮은 수익원부터 쌓는다. 직매입 커머스·자체 에스크로·생체거래는 하지 않는다.

이 문서는 국내외 반려동물 앱의 구독·AI·커머스·중고거래·광고 수익모델 리서치를 바탕으로 Pawloop의 수익화 원칙, 후보 전수 평가, 단계별 로드맵, 구독/AI 설계안을 정의한다. 수치 중 시장 조사로 확인된 것은 출처를 달았고, **Pawloop 자체 전망치는 전부 (가정)으로 표기**했다.

- 제품 방향: [비전](vision.md) · [컨셉](concept.md) · 기능 범위: [가족 케어 + 채팅](feature-family-care.md)
- 빌드 순서: [로드맵](../05-build/roadmap.md) · [MVP 범위](../05-build/mvp-scope.md)

## 1. 수익화 원칙

### 1-1. 무엇을 무료로 두는가 — 성장 루프는 과금하지 않는다

| 영역 | 무료 유지 이유 |
| --- | --- |
| **산책 GPS 기록(기본)** | 데이터 축적 = Pawloop의 자산. 기록 자체에 과금하면 데이터가 안 쌓임. 해외 기록 앱들도 "기록은 무료, 심화는 유료"가 표준 경계(Tractive·11pets·DogLog) |
| **동반장소 지도(기본 탐색)** | 광고 지면이 될 트래픽의 원천. 탐색을 막으면 광고 모델 자체가 붕괴 |
| **가족 케어 공유(기본: 물/밥/산책 체크)** | 가족 초대가 곧 바이럴 루프. 초대 = 무료 신규 유저 |
| **커뮤니티·가족/크루 채팅** | 리텐션과 지역 밀도의 원천. 당근마켓도 거래·커뮤니티는 무료, 수익은 광고(매출의 99%)([테크M](https://www.techm.kr/news/articleView.html?idxno=113455)) |

### 1-2. 무엇을 유료로 하는가

- **개인에게는**: 쌓인 데이터의 *심화 가치* — 장기 히스토리, AI 리포트, 무제한 공유, 백업/내보내기, 광고 제거 (해외 기록 앱의 검증된 경계).
- **사업자에게는**: Pawloop이 모은 *반려인 트래픽과 동선 데이터* — 지역 업체 광고, 프리미엄 노출, (장기) 보험·커머스 제휴.

### 1-3. 1인 개발 현실성 원칙

1. **운영부담이 낮은 것부터**: 광고 지면·어필리에이트 링크·구독은 코드로 끝남. 사람이 붙어야 하는 것(에스크로 분쟁 중재, 수의사 상담 운영, 재고/물류)은 후순위 또는 제외.
2. **재고·정산·법적 책임을 지지 않는다**: 직매입 커머스(어바웃펫 누적 결손 726억 후 매각, [비즈워치](http://news.bizwatch.co.kr/article/consumer/2025/04/07/0044)), 자체 에스크로(전자금융 규제), 생체거래(동물보호법 허가제)는 구조적으로 배제.
3. **구독은 마진 보완 수단이지 구원투수가 아니다**: Wag!는 구독 침투율 50%에도 Chapter 11에 갔다([Bondoro](https://bondoro.com/wag/)). 유닛이코노믹스가 성립하는 수익원(광고·제휴)을 먼저 깐다.
4. **없는 트래픽에 광고를 팔 수 없다**: 수익화 착수 시점은 기능이 아니라 사용자 밀도가 결정한다. P1은 "돈 벌 준비(지면·데이터 설계)"이지 "돈 벌기"가 아님.

## 3. 추천 로드맵

### P1 — 지금(출시~초기, 유저 <수천): "돈 벌 준비"

수익 목표 0원. 대신 **나중에 팔 자산의 골조**를 심는다.

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 광고 지면 설계 | 장소지도 카드 리스트에 '제휴 업체' 슬롯 타입을 미리 설계(데이터 모델·UI). 채우는 건 P2 | 당근도 지면(피드)이 먼저 있었고 광고는 나중([테크M](https://www.techm.kr/news/articleView.html?idxno=103652)) |
| 케어로그 스키마에 수익화 훅 | 밥/사료 로그에 '제품(사료명)' 선택 필드 → P2 소진 예측 어필리에이트의 재료 | 리서치 3 §5 사료 어필리에이트 |
| AI 주간 리포트 무료 베타 | LLM으로 산책+케어 요약 리포트(주 1회). 무료로 뿌려 습관·기대치 형성, P2에 유료 경계로 이동 | AI 건강체크는 리텐션 도구일 때 강함(Ollie 사례) |
| 히스토리 보존 정책 선언 | "무료는 최근 N개월 상세 조회" 정책을 **처음부터 고지**(나중에 뺏으면 반발) | Tractive Premium 365일 히스토리 경계 |
| 인앱결제 없이 배포 | 결제 인프라는 P2에. P1은 리텐션 지표(주간 산책 기록률, 가족 초대율)에 집중 | 1인 리소스 집중 |

### P2 — 사용자 확보 후(동네 단위 밀도 형성, 수천~수만): "첫 매출"

| 항목 | 구체안 | 가격안(원화) | 근거 |
| --- | --- | --- | --- |
| **Pawloop+ 구독 출시** | §4 설계안. AI 리포트·무제한 히스토리·가족 무제한·광고 제거 번들 | **월 3,900원 / 연 29,000원**(월 환산 ~2,417원, 첫 달 무료) | DogLog $3.99/월·연 $39.99, 핏펫플러스 2,900원 — 월 3~5천원이 심리적 상한(리서치 1 §4) |
| **커머스 어필리에이트** | 케어로그 사료 소진 예측 푸시 + 커뮤니티 후기 상품 링크. 쿠팡 파트너스부터 | 수수료 수취(펫 카테고리 최대 8%) | [Savvy KR](https://savvykr.com/coupang-partners-commission-rate-guide/) |
| **지역 광고 파일럿** | 밀도 높은 1~2개 동네에서 펫 미용실/카페 5~10곳 수동 영업. 지도 상단 고정 노출 월정액 | **월 3만~10만원/업체(가정)** — 당근 CPC 300~600원 환산 대비 저렴하게 시작 | 펫닥 수의사 월 10만원 구독 사례([Vertical Platform](https://verticalplatform.kr/archives/7629)) |
| **펫보험 제휴 링크** | 케어/건강 기록 화면 + 신규견 등록 온보딩에 보험 비교 페이지 제휴 링크(리드당/계약당) | 제휴 조건 따름 | 중개수수료 보험료의 3~3.5% 수준([시사저널e](https://www.sisajournal-e.com/news/articleView.html?idxno=404859)) |
| **나눔/직거래 게시판** | 결제 미개입, 생체·의약품 금칙어 필터+신고 필수(§6) | 무료(광고 지면화가 목적) | 리서치 3 §2 체크리스트 |

### P3 — 규모(수만~수십만, 지역 다수 커버): "구조화"

| 항목 | 구체안 | 근거 |
| --- | --- | --- |

## 4. 구독 설계안 — Pawloop+

### 4-1. 무료 vs Pawloop+ 경계표

원칙: **기록하는 행위는 전부 무료, 쌓인 데이터의 심화 가치가 유료.**

| 기능 | 무료 | Pawloop+ | 경계 근거(사례) |
| --- | --- | --- | --- |
| 산책 GPS 기록 | 무제한 기록 | 동일 | 기록 과금 금지 원칙 |
| 산책/케어 히스토리 상세 | 최근 **3개월** | **무제한 + 연간 리뷰** | Tractive Premium 365일 히스토리 |
| AI 리포트 | 월 1회 요약(맛보기) | **주간 리포트 + 이상 패턴 알림** | Dogo 개인화 플랜, Fi 활동 분석 |
| AI 케어 Q&A(트리아지) | 월 N회(예: 5회) | 무제한 | AskVet·Petcube 무료 N회+구독 패턴 |
| 가족 구성원 | **2명** | **무제한 + 크루 확장** | Dogo 개 5+가족 5, 핏펫플러스 패밀리 2명, Tractive family sharing |
| 반려동물 등록 | 2마리 | 무제한 | 11pets 무제한 등록 |
| GPS 경로 내보내기(GPX)·백업 | — | 제공 | Tractive GPS export, 11pets 무제한 저장('데이터 상실 공포'를 지불 동기로) |
| 광고 | 노출 | **제거** | 단독으론 약하나 번들 구성요소로(리서치 1 §3) |
| 산책 코스 추천(AI 큐레이션) | 기본 인기 코스 | 날씨·체중·최근 산책량 반영 개인화 | 단독 유료화 어려움 → 구독 묶음(리서치 2 §1-6) |

### 4-2. 가격안

| 플랜 | 가격 | 비고 |
| --- | --- | --- |
| 월간 | **3,900원** | 첫 달 무료(핏펫플러스 패턴) |
| 연간 | **29,000원**(월 ~2,417원, 38% 할인) | 연간 유도로 이탈 방어. DogLog 연 $39.99 대비 국내 저항 감안해 하향 |

- 벤치마크: DogLog $3.99/월·$39.99/연, 핏펫플러스 2,900원/월, 11pets 연 ~€69. 순수 기록/케어 구독은 **월 3,000~5,000원이 심리적 상한**(리서치 1 §4). Dogo급($29.99/월)은 '훈련 성과물'이 있을 때만 성립하므로 배제.
- 가격 인상 여지: AI 리포트 품질이 검증되면 월 4,900원 테스트(Dogo는 가격·기능 재설계로 전환율 +9.5%, ARPU +13% — [OpinionX](https://www.opinionx.co/blog/dogo-case-study)).

### 4-3. 러프 수익 시뮬레이션 (전부 가정)

전환율 근거: Wag! Premium 침투율 34→50%는 '수수료 절감형'이라 예외적 고전환. 순수 기능 구독인 Pawloop+는 훨씬 보수적으로 **유료 전환율 1~3%(가정)** 를 상정. 공개된 국내 펫 앱 기능 구독 전환율 통계는 없음.

| 시나리오 | MAU(가정) | 전환율(가정) | 구독자 | 월 구독 매출(ARPU 3,000원 가정*) |
| --- | --- | --- | --- | --- |
| 보수 | 5,000 | 1% | 50 | 15만원 |
| 기본 | 20,000 | 2% | 400 | 120만원 |
| 낙관 | 50,000 | 3% | 1,500 | 450만원 |

\* 월간 3,900원·연간 환산 2,417원 혼합 + 앱스토어 수수료(15%, 소규모 사업자 기준) 차감 전 기준의 러프 평균. 수수료 차감 시 약 85% 수취.

**해석**: 구독 단독으로는 P2 규모에서 월 100만원대 — 생활비가 아니라 서버비+LLM 비용을 덮는 수준. **구독은 '광고 없는 경험+AI'라는 제품 품질 신호 겸 보조 수익**으로 보고, 주 수익은 지역 광고·제휴에서 기대하는 것이 현실적. (Wag! 교훈: 구독이 사업을 구하지 못한다.)

### 5-3. 비용 구조 (가정)

- 리포트 1건 = 케어로그 요약 입력(수천 토큰) + 출력(~1천 토큰) 수준. 경량 모델 기준 **건당 수 원~수십 원 수준(가정, 모델 단가에 따라 변동)**. 구독자 1명당 월 4~5회 리포트 + Q&A를 합쳐도 **월 원가 수백 원 미만(가정)** — 구독가 3,900원 대비 마진 성립.
- 비용 통제: 무료 유저는 월 1회 리포트 + Q&A 월 N회로 토큰 상한. 리포트는 배치(주 1회 일괄 생성)로 처리해 피크 비용 평탄화. 요약 전처리(집계는 SQL, LLM엔 집계 결과만)로 입력 토큰 최소화.
- 모델 선택·단가는 도입 시점에 재조사(모델 가격 변동 큼).

## 6. 중고거래/커머스 판단

### 6-1. 결론

- **수수료형 중고거래(에스크로 포함): 도입하지 않음.** 근거: ① 당근조차 중고거래는 무료고 수익의 99%가 광고 ② 번개장터 6% 수수료는 반발·이탈을 낳음 ③ 2026년부터 C2C 분쟁 1차 조정 책임이 플랫폼에 부과(연 5,848건 규모의 분쟁 카테고리, [아주경제](https://www.ajunews.com/view/20260628091645100)) ④ 자체 안전결제는 전자금융 규제 대응 필요 — 전부 1인 운영부담 최상.
- **직매입/재고 커머스: 도입하지 않음.** 펫프렌즈(1위) 영업이익률 0.4%, 어바웃펫 매각(리서치 3 §1).
- **최소 형태로 도입: 결제 미개입 '동네 펫용품 나눔/직거래 게시판'(P2).** 커뮤니티 시너지(켄넬·유모차·미용용품 등 고가 내구재 수요 존재, [KPMG](https://assets.kpmg.com/content/dam/kpmg/kr/pdf/2024/issue-monitor/kpmg-korea-petmarket-trends-20240604.pdf))는 취하되, 돈은 게시판이 아니라 **그 트래픽 위의 지역 광고**로 번다.

### 6-2. 도입 시 필수 체크리스트 (법적 필수 포함)

| # | 항목 | 성격 |

### 6-3. 커머스는 어필리에이트로

- 쿠팡 파트너스 반려동물 최대 8%(카테고리 최상위)로 시작 — 무재고·무정산·무CS.
- 배치: ① 케어로그 사료 소진 예측 푸시("사료가 떨어질 때쯤이에요") ② 커뮤니티 후기 글의 상품 링크 ③ AI 영양 가이드의 추천 제품. **문맥 없는 배너식 커머스는 하지 않음**(신뢰 훼손).
- 트래픽이 커지면 사료 브랜드 D2C 직제휴로 수수료율 협상(펫프렌즈도 수익은 광고·PB에서 남).

### 7-2. 열어둘 질문

1. **전환율 실측**: 유료 전환율 1~3%는 순수 가정 — P2 출시 후 첫 3개월 실측으로 시뮬레이션 전면 갱신.
2. **광고 단가 검증**: 지역 펫 업체가 월 3만~10만원을 낼지는 파일럿 전엔 모름. 당근 대비 '반려인 100% 타겟' 프리미엄이 실제로 먹히는가?
3. **보험 제휴 창구**: 소형 앱이 접근 가능한 GA/제휴 조건 실사 필요(핏펫·페오펫이 어떤 계약 형태인지 공개 정보 부족).
4. **AI 리포트의 지불 가치**: '주간 리포트'가 실제 결제를 일으키는 앵커인지, 히스토리 무제한이 더 센지 — 유료 경계 A/B 필요(Dogo의 MaxDiff/컨조인트 방식 참고).
5. **B2B 전환 시점**: 병원·미용실 대상 SaaS(PetDesk 모델)로 과금 주체를 넘기는 것이 P3인지 P4인지 — 장소 데이터·리뷰 자산의 성숙도에 달림.
6. **케어로그 기반 데이터 제휴**: 보험사에 익명 통계를 제공하는 모델의 법적·윤리적 경계(위치정보법, 개인정보보호법) 사전 검토.
