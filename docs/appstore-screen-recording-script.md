# 애플 심사용 화면 녹화 대본

애플 요구(Guideline 2.1, 2026-09-18 반려 메일 1번):

> A screen recording **captured on a physical device**, running the latest operating system…
> The recording **must begin with launching the app** and show the typical user flow.
> 안에 반드시 들어가야 할 것: **계정 가입·로그인·계정 삭제**, **사용자가 올린 글과 그 신고·차단 수단**.

목표 길이 **3~4분**. 아이폰 17 로 찍습니다.

---

## 녹화 전 준비 — 순서가 중요합니다

### 1. 빌드 3 설치 (제가 합니다)

아이폰을 맥에 꽂고 잠금을 푸신 뒤 알려 주세요. 심사에 올릴 그 코드로 릴리스 빌드를 깔아
드립니다. **지금 폰에 있는 건 옛 빌드라 그대로 찍으면 안 됩니다.**

### 2. 지금 있는 애플 계정을 지웁니다

운영 DB 에 내 애플 계정이 이미 있습니다. 그대로 두면 녹화에서 애플 버튼을 눌러도
**그냥 로그인**이 되고, 애플이 요구한 *account registration* 장면이 안 나옵니다.

> 앱 열기 → `Apple로 계속하기` → 홈 → **우상단 동그란 프로필** → `설정` → `회원 탈퇴`
> → `정말로 탈퇴하기` → `탈퇴하기`

### 3. 커뮤니티에 글을 두어 개 채웁니다 (권하지만 필수는 아님)

지금 운영 DB 에 **글이 하나뿐**입니다. 커뮤니티 탭이 휑하면 "완성된 앱" 으로 안 보입니다.

> 로그인 화면 → `Google로 시작하기` (내 구글 계정) → 커뮤니티 탭 → `글쓰기`
> → 사진 붙여서 두 개쯤 → **우상단 프로필 → `로그아웃`**

**구글로 쓰는 것이 핵심입니다.** 신고 버튼은 *남의 글*에만 뜹니다(`post_detail_screen.dart:400`
— `!_isMine(author)`). 녹화는 애플 계정으로 하니까, 구글로 쓴 글이 그때 "남의 글" 이 됩니다.

### 4. 앱을 지웁니다

홈 화면에서 포루프 아이콘 길게 누르기 → `앱 삭제`. 그래야 첫 실행 소개부터 나옵니다.
(`intro_seen_v1` 이 앱과 함께 지워집니다.)

그리고 제가 다시 깔아 드립니다. **이 상태에서 녹화를 시작합니다.**

### 5. 찍기 전 마지막 점검

- **방해금지 모드**를 켜 주세요. 전화나 알림이 뜨면 다시 찍어야 합니다
- 배터리·와이파이가 보이는 상태면 됩니다 — 가릴 필요 없습니다
- **밖에 나가실 준비를 하세요.** 9번에서 실제로 2분쯤 걸어야 경로가 그려집니다

## 녹화 대본

**녹화 버튼을 먼저 누르고, 홈 화면이 보이는 상태에서 시작합니다.**

| # | 무엇을 | 왜 (애플이 보려는 것) |
|:--|:--|:--|
| 1 | **홈 화면에서 포루프 아이콘을 탭** | `must begin with launching the app` — 이미 열린 화면에서 시작하면 안 됩니다 |
| 2 | 소개 3장. `다음` → `다음` → `시작하기` | 첫 실행 |
| 3 | `기기 접근권한 안내` 를 **3초쯤 보여주고** 천천히 한 번 스크롤 → `확인했어요` | 권한을 왜 받는지 설명하는 화면이 있다는 것 |
| 4 | 로그인 화면을 2초 보여줍니다 | 카카오·Google·Apple·`그냥 둘러보기` 넷이 보이게 |
| 5 | **`Apple로 계속하기`** → 애플 로그인 완료 | **account registration + login.** 심사자가 자기도 이렇게 들어온다는 걸 봅니다 |
| 6 | 약관 동의 화면. 항목 하나를 **열어서 전문을 잠깐 보여준 뒤 닫고**, `전체 동의` → `동의하고 시작하기` | 동의를 받는다는 것 + 심사자가 막힐 자리를 미리 보여줌 |
| 7 | 온보딩 → `우리 아이 등록하기` → 이름·견종·크기 입력 → 완료 | 가입 직후 흐름 |
| 8 | 동네 고르기가 뜨면 → `현재 위치로 찾기` → 후보에서 하나 고르기 | 이번에 고친 화면입니다. 한국에서는 진짜 근처가 나옵니다 |
| 9 | 홈을 3초 보여주고 → **`산책 시작`** → 위치 안내 시트 `허용하기` → iOS 대화상자 **`앱을 사용하는 동안 허용`** | 핵심 기능 진입 |
| 10 | **실제로 2분쯤 걷습니다.** 지도에 선이 그려지고 거리·시간이 오르는 걸 보여주세요. 중간에 `배변`·`물` 을 한 번씩 탭하고, 카메라로 사진 한 장 | **이 앱이 무엇을 하는 앱인지** — 여기가 영상의 심장입니다 |
| 11 | `끝내기` → 완료 시트(경로·거리·시간) 3초 → `기록 저장하기` → 메모 적고 저장 | 기록이 남는다는 것 |
| 12 | 저장 뒤 `보기` → 산책 기록 목록 → 항목 하나 열어 상세 | 데이터가 쌓인다는 것 |
| 13 | 하단 탭 **`지도`** → 지도로 토글 → `산책로`·`동물병원` 칩을 눌러 보기 → 장소 하나 열기 | 장소 정보 기능 |
| 14 | 하단 탭 **`커뮤니티`** → `글쓰기` → 글 쓰고 **`사진 추가`** 로 사진 붙여 게시 | **user-generated content** |
| 15 | 목록에서 **아까 구글로 쓴 글**을 엽니다 → 우상단 **`신고`** → 사유 고르기 → **`이 사람 가리기` 체크** → 접수 | **content reporting + blocking.** 애플이 콕 집어 요구한 장면 — 천천히, 또렷하게 |
| 16 | 하단 탭 **`채팅`** → 방 하나 → 상대 말풍선 **길게 누르기** (신고·가리기 시트를 보여주고 닫기) | 채팅에도 같은 수단이 있다는 것 |
| 17 | **우상단 프로필 아바타** → `내 프로필` → `설정` | 계정 삭제로 가는 길 |
| 18 | `회원 탈퇴` → 안내 문구를 **3초 보여주고** → `정말로 탈퇴하기` → 확인 창 → `탈퇴하기` | **account deletion — 애플이 "필수" 라고 한 것** |
| 19 | 로그인 화면으로 돌아온 것을 2초 보여주고 **녹화 종료** | 계정이 실제로 없어졌다는 것 |

## 반드시 지킬 것

- **15번과 18번을 서두르지 마세요.** 애플이 이름을 대서 요구한 둘입니다. 버튼을 누르기 전에
  한 박자 쉬고, 누른 뒤 화면이 바뀌는 걸 보여준 뒤 넘어가세요
- **10번은 진짜로 걸어야 합니다.** 제자리에 서 있으면 거리가 0.0km 로 남고, 심사자는
  "산책 기록이 안 된다" 고 읽습니다
- 소리는 없어도 됩니다. 말로 설명하지 않아도 됩니다 — 애플은 화면만 봅니다
- 중간에 잘못 눌렀으면 **그냥 이어서 하세요.** 사람이 쓰는 모습이라 오히려 자연스럽습니다.
  다만 오류 화면이 뜨면 멈추고 알려 주세요

## 다 찍으면

1. 맥으로 옮깁니다 (에어드롭이나 케이블)
2. 유튜브에 **일부공개(Unlisted)** 로 올립니다 — 심사자가 로그인 없이 바로 봅니다
   (비공개로 올리면 심사자가 못 봅니다)
3. 링크를 [appstore-review-notes.md](appstore-review-notes.md) 의 `[VIDEO_LINK]` 자리에 넣습니다
4. 그 문안을 **심사 메시지 답장**과 **`앱 심사 정보 → 메모`** 두 군데에 넣습니다
5. 빌드를 `2.0.0 (3)` 으로 갈아 끼우고 재제출합니다
