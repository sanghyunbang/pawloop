# 화면 명세 (Screen Spec)

> Pawloop(포루프) 앱의 화면별 상세 명세 — 목적 · 구성요소 · 상호작용 · 데이터. 실제 `app/lib/v2/screens/` 구현 기준으로 작성.

산책을 wedge로 시작하는 반려(강아지) 산책·동반장소·커뮤니티 앱의 현재 구현(감정 도메인 제거 완료)을 화면 단위로 정리한다. 관련 문서: [ERD](../03-database/erd.md), [공개데이터](../02-architecture/external-data.md).

> 참고: 프로필/글상세/기록작성/편집/내기록 화면은 탭이 아니라 push 라우트로 열린다(바텀네비 위에 전체화면).

## 1. 홈 (`today_screen.dart` · `TodayScreen`)

### 목적
"오늘 우리 아이랑 산책 갈까요?" — 반려견 히어로 + 오늘 산책 요약 + 산책/코스 진입점. 앱 첫 화면.

### 구성요소 (위→아래)
1. **헤더**: 날짜 라벨(`YYYY. MM. DD 요일`, `DateTime.now()` 파생) + `"{강아지 이름}랑\n산책 갈까요?"` 대형 타이틀 + 우측 상단 `ProfileAvatar`.
2. **반려견 히어로**(가운데): 원형 그라데이션(peach) 배경 + 강아지 아바타(`dog.avatarAsset`, 96px) → 이름(23pt) → `{견종} · {나이} · {크기}` 서브텍스트.
3. **오늘 산책 요약 카드**(GlassCard): 3분할 셀 — `{count}회 오늘 산책` / `{km}km 거리` / `{minutes}분 시간`. **서버 목록 + 전송 대기 초안**을 합쳐 오늘 것만 접는다(#145). 대기 중인 것이 있으면 아래에 `전송 대기 N건`, 서버를 못 불렀으면 `기록을 불러오지 못했어요` — **0 을 그냥 보여 주지 않는다**(0 은 "한 번도 안 걸었다" 로 읽힌다).
4. **CTA 2버튼**: `산책 시작`(flex 3, warm 채움) / `코스 찾기`(flex 2, 흰색 아웃라인).
5. **산책 안전 지수 카드**(`WalkSafetyCard`, #336): 판정 아이콘 + 한 줄(`지금 나가기 좋아요` / `짧게 다녀오세요 · 바닥 7초 룰 확인` / `지금은 피하고 저녁 7시 뒤에` / `옷 입히고 짧게 다녀오세요`) + 근거(`26°C · 미세먼지 보통(성수)`). 누르면 7초 룰·시간대 시트. 키·위치·기상청 응답이 없으면 **카드가 없다**.
6. **급할 때 한 줄**(`_emergency`, #337): `급할 때 · 가까운 동물병원`. 누르면 `EmergencyVetsSheet` — 가까운 병원 **셋**(이름 · 거리 · 주소 · 전화 버튼). 이름에 24시가 있으면 `24시 · 이름 기준` 배지. 위치가 없으면 목록 대신 "위치를 켜면 가까운 곳부터 찾아 드려요".

### 상호작용
| 요소 | 동작 |
| --- | --- |
| 산책 시작 | `WalkTrackingScreen` push |
| 코스 찾기 | `RootTab.index.value = 1`(지도 탭 전환) |
| ProfileAvatar | (공통 아바타 위젯) 프로필 진입 |

### 데이터
- `kMyDog`(ValueNotifier<DogProfile>) → 이름·견종·나이·크기·아바타. 편집 화면과 실시간 연동.
- `WalkFeedData.today`(count/km/minutes) — `GET /api/walks` + 초안 큐. 안전 지수는 **서버**가 기상청·에어코리아를 부르고 앱은 5km 격자만 보낸다(`GET /api/walk-safety/now`, #336). 급할 때 목록은 `PetPlacesRepository.fetchNearby(contentTypeId: 'vet')` — 거리는 기기 안에서 잰다(#337).

## 2. 지도 — 리스트/지도 (`explore_screen.dart` · `ExploreScreen`)

### 목적
"우리 아이랑 갈 수 있는 곳" — 관광공사 반려동물 동반여행(KTO) 장소 + 병원/펫샵(행정안전부 인허가)/산책로(두루누비) 레이어를 **리스트/지도 토글**과 **카테고리 필터**로 탐색. 셋 다 실데이터다(#291).

### 공통 컨트롤
- **뷰 토글**(`_viewToggle`): `list`(view_agenda) / `map`(map). 활성 시 warm 그라데이션. `initialView`로 진입 뷰 지정(셸의 `RootTab.exploreView`).
- **카테고리 필터 칩**(`_catChips`, 가로 스크롤): `전체` + `kPetCategories` 9종. 활성 칩은 카테고리 색으로 채움. 누르면 칩 키를 붙여 **다시 조회**한다(받아 놓은 80곳 안에서 거르지 않는다 — #291 실측). 늦게 돌아온 옛 조회는 순번으로 버린다. 산책로 칩만 반경 없이 가까운 코스 20개다(2026-09-06 결정, #291).
  - 카테고리: 여행지(12)/카페·식당(39)/레포츠(28)/숙박(32)/쇼핑(38)/문화(14) = KTO contenttypeid, + 병원(vet)/펫샵(shop)/산책로(trail) = 공공데이터 레이어(#291). 항목은 `PetPlace.categoryKey` 로 견준다.
- **검색바**: 플레이스홀더만(`카페, 공원, 산책로...`) — **미구현(비활성 표시용)**.

### 리스트 뷰 (`_listView`)
- 타이틀 `지도` + 서브 `우리 아이랑 갈 수 있는 곳` + `ProfileAvatar`.
- 상태별 분기:
  - 로딩 → `CircularProgressIndicator`.
  - `trail` 필터 → 두루누비 코스 카드(시작점 기준 거리순). 카드에 `summary`("2.6km · 약 40분 · 쉬움 · 순환")가 한 줄 더 붙는다(#291).
  - 결과 없음 → `_emptyBox`(paw 이미지 + "이 지역엔 등록된 곳이 없어요").
  - 결과 있음 → 헤더(`반려동반 가능 · N곳`, 출처 한 마디 — 칩에 따라 `관광공사`/`행정안전부 인허가 · 전국`/`두루누비 · 한국관광공사`) + `_placeCard` 목록.
- **장소 카드**(`_placeCard`): 썸네일(firstimage 또는 카테고리색 폴백) + 이름 + 카테고리 태그 + 거리(`near_me`) + 주소. 탭 시 바텀시트.

### 지도 뷰 (`_mapView`)
- **NaverMap**(`flutter_naver_map`): 초기 중심 서울시청(37.5665, 126.9816), zoom 12(min 9 / max 18), 위치버튼 on, ko 로케일.
- 상단 오버레이: 검색바(`이 지역에서 찾기...`, 더미) + 뷰 토글 + ProfileAvatar + 카테고리 칩.
- **마커**(`_refreshMarkers`): 필터된 장소마다 카테고리색 원형 핀(`NOverlayImage.fromWidget`), 탭 시 바텀시트.
  - 산책로 항목의 시트를 열면 → 선을 `GET /api/places/trails/{courseId}/route` 로 받아 폴리라인(카테고리색)을 얹고 카메라를 선에 맞춘다(#291). 못 받으면 시작점 마커만 남는다.
- 좌하단 **범례**(`_legend`): 카테고리 9종 색 + 아이콘 목록(#328). 마커는 `NClusterableMarker` — 겹치면 숫자 하나로 접힌다.
- 로딩 시 상단 "주변 장소 불러오는 중..." 카드.

### 장소 상세 바텀시트 (`_showPlaceSheet`)
- 카테고리색 아이콘 박스 + 이름 + 카테고리 태그 + 거리 + 닫기(X).
- 요약(`summary`, 있을 때) / 주소(`place_outlined`) / 전화(`call_outlined`, 있을 때) + 출처 배지(`반려동물 동반 가능 (관광공사)` · `동물병원 · 행정안전부 인허가` · `걷기여행길 · 두루누비(한국관광공사)`).
- 병원이고 **이름에 24시가 있으면** 카테고리 태그 옆에 `24시 · 이름 기준` 배지(#337). 진료시간을 주는 공공 데이터가 없어서 이름으로 짐작한 것이고, 그 사실을 배지가 함께 말한다.
- 병원 칩을 고르면 칩 줄 끝에 **`24시` 토글**이 붙는다(#337) — 이름 기준으로 거르고, 카테고리를 바꾸면 꺼진다. 조회를 다시 하지 않고 받아 둔 목록에서 거른다.
- 걸을 만한 곳(여행지·카페·식당·레포츠·산책로)이면 시트의 첫 동작이 **`여기서 산책 시작`**(#338) — `startWalk(place:)` 로 추적 화면까지 장소가 따라가고, 저장 화면의 이름 칸이 그것으로 채워진다.
- 산책로 칩을 고르면 칩 줄 끝에 **`이웃 코스` 토글**이 붙는다(#339). 켜면 공공데이터 산책로 대신 **사람들이 올린 공개 코스**를 본다 — 서버는 한 벌을 그냥 주고 **가까운 20개는 기기가** 고른다(A안 #235). 누르면 상세를 받아 선을 그리고 `이 코스 다시 걷기` 를 준다(추적 화면에 연한 선으로 깔린다). **공모전 빌드에서는 이 줄이 화면에 없습니다** — 코스의 선은 서버가 `walk.path` 를 베껴 만드는데, A안(#235)에서는 그 선이 올라가지 않아 서버의 모든 산책이 `path IS NULL` 입니다. `--dart-define=UPLOAD_LOCATION=true` 를 켜면 함께 돌아옵니다(`LocationUploadPolicy.sharesRoutes`). 

### 데이터
- `PetPlacesRepository.fetchNearby(lat, lng, radius:8000, numOfRows:80)` → **`GET /api/places/nearby`**(우리 백엔드). 응답은 계약의 `Place` 다 — `lat/lng/contentTypeId/addr/image/tel/distM`. **KTO 의 `mapx/addr1/firstimage` 가 아니다**: 그 모양을 해석하는 일은 서버가 한다(#40).
- 병원/펫샵/산책로는 서버가 카탈로그 한 벌에 이어 붙인다(#291) — 앱에 레이어 데이터가 없다. `explore_has_no_dummy_layer_test` 가 가짜 좌표·이름이 돌아오지 않는지 잰다.
- 필터 로직: `_filtered`(null→전체, 그 외→`categoryKey` 일치). `_only24h` 가 켜져 있으면 `isTwentyFourHourByName(title)` 까지 통과한 것만(#337).

## 3. 산책 트래킹 (`walk_tracking_screen.dart` · `WalkTrackingScreen`)

### 목적
실시간 GPS 산책 트래킹 화면 — 지도 위 경로 폴리라인 + 라이브 스탯(거리/시간/페이스). **실 GPS 다** — `geolocator` 스트림(5m 간격)이 `walk.path` LINESTRING 으로 저장된다(#145).

위치를 못 잡으면 **지도를 아예 만들지 않고** 이유를 말하는 화면을 띄운다. 이유는 **여섯**이고(`LocationDenial`) 각각 사용자가 할 일이 다르다 — 약관 미동의 · 앱 안 일시중단 · 기기 위치 서비스 꺼짐 · 권한 거부 · 권한 영구 거부 · 측정 실패. 예전에는 서울숲 근처 가짜 루프를 그리고 거리를 올렸는데, 그것을 저장하면 부산에서 권한을 끈 사람의 산책이 서울숲에 기록됐다(#160).

### 구성요소
1. **풀스크린 NaverMap**: **위치 판정이 끝난 뒤에야** 만든다 — 초기 중심은 `LocationService.locate()` 가 준 첫 실측 좌표, zoom 16. 판정 전에 지도를 만들면 대기 중 찍힌 점이 경로 앞머리에 남는다(#145 실측).
2. **상단 뒤로가기 버튼**(원형, 좌상단): 타이머 취소 후 pop.
3. **한 손 기록 줄**(#340): 스탯 패널 **바로 위**, 패널이 접히든 펼쳐지든 항상 보인다 — 눌러야 할 때 패널을 먼저 펼쳐야 한다면 그건 이미 한 탭이 아니다. 버튼 셋(배변·마킹·물)은 각각 56dp 이상이고, 누른 만큼 배지에 숫자가 붙는다. **5초 안에 같은 버튼을 다시 누르면 취소**이고 그동안 라벨이 `다시 누르면 취소` 로 바뀐다. 아이콘은 시스템 이모지가 아니다(기기마다 다른 그림이 된다) — 배변·마킹은 `CustomPainter` 가 그리고 물은 케어 카드와 같은 물방울이다.
4. **하단 라이브 패널**(흰색 라운드 카드):
   - 상태 표시: `산책 기록 중`(핑크 점) / `일시정지됨`(회색) + `실시간 GPS`.
   - **3-스탯**(대형 26pt): `{km}`(km) / `{mm:ss}`(시간) / `{페이스}`(분'초"/km).
   - 컨트롤 2버튼: `일시정지/재개`(토글) / `종료`(warm 그라데이션).
   - 종료 시트의 요약에 `배변 2회 · 물 1회` 한 줄이 붙는다 — **하나도 안 눌렀으면 줄 자체가 없다**(0회를 적으면 못 한 일처럼 읽힌다).

### 상호작용 · 동작 로직
| 요소 | 동작 |
| --- | --- |
| `_boot()` | `LocationService.locate()` 로 첫 위치를 잡고 그 결과로 지도를 만든다. 못 쓰면 `WalkLocationDeniedScreen` |
| 위치 스트림 | `Geolocator.getPositionStream`(5m 간격). 점이 올 때마다 `_km += Haversine 거리`, `_path` 와 `_pathT`(점별 델타 초, #155)에 **같은 `setState` 안에서** 함께 추가 → `_drawPath`(폴리라인 `#FF7E8A` + head 마커), 카메라 헤드 추적 |
| 1초 Timer | `_seconds++` 만 한다. 일시정지 중에는 안 흐른다 — 그래서 `_pathT` 의 델타가 건너뛰면 그 사이가 멈춘 구간이다 |
| 일시정지/재개 | `_paused` 토글(타이머는 유지, tick만 스킵) |
| 종료 | `_finish()` — 타이머 취소 + **완료 바텀시트** |
| 뒤로가기 | 타이머 취소 후 pop |

### 완료 바텀시트 (`_finish`)
- `산책 완료! 🐾` + 3-스탯(시간/거리/페이스).
- 경로 미리보기(타일 없이 `RouteCanvasPainter` 가 그린다) + `경로 사진 저장` → PNG 를 갤러리 앨범 Pawloop 에만 저장(#310). 점이 둘 미만이면 "경로가 짧아 그림은 못 만들었어요".
- `기록 저장하기`(warm) → `CreateScreen(prefillPlace: '오늘 산책')`로 `pushReplacement`.
- `저장 안 함` → 시트 + 화면 pop.

### 데이터
- 상태: `_path`(진행 경로), `_pathT`(점별 델타 초 — `_path` 와 길이가 같다), `_seconds`, `_km`, `_paused`, `_denial`(위치 판정 — `null` 이면 판정 전이라 지도를 안 만든다).
- **영속화된다.** 종료하면 저장 화면을 거쳐 `POST /api/walks` 로 `walk.path`(LINESTRING SRID 4326)에 남고 점별 시각은 `path_t` 다(#145·#155). 못 보내면 초안이 큐에 남아 나중에 다시 보낸다(`walk_outbox`).
- 거리 계산: Haversine(`_dist`), 페이스 = `_seconds / _km` 파생.

## 4. 산책 통계 (`insight_screen.dart` · `InsightScreen`)

3. **주간 거리 막대그래프 카드**(`fl_chart` BarChart):
   - 범례: `오늘`(핑크 점) / `평일`(연보라 사각).

### 데이터 (모두 파생/상수)
- `GET /api/walks/stats/weekly` 의 `weekKm`(월~일, 주 경계는 **KST**) + 전송 대기 초안, `kWeekDayLabels`.
- 파생: `_totalKm`(합), `_walkCount`(>0 개수), `_avgKm`, `_maxKm`(축 스케일).
- `_topPlaces` — 항상 빈 목록(위 4번 참조).

## 5.5 일정 (`schedule_screen.dart` · `ScheduleScreen`)

**목적**: 앞으로 할 일을 가족이 함께 본다 — 병원 예약 · 약 · 미용 · 목욕 · 사료 · 산책. 지금까지 앱은 **지나간 일만** 알았고(케어 로그는 서버 시계라 미래를 못 넣는다), 그래서 가족은 병원 일정을 채팅으로 조율하고 그 결정이 스크롤 위로 사라졌다. (일정 탭, #419 · 서버 #418)

**구성**
1. **머리말**: `2026년 10월` + 지난 달 · 다음 달.
2. **필터 칩**: `전체`(기본) · 아이별 · `가족`. 아이 필터는 서버의 `dogId` 로 가고 주인과 **겹쳐 쓸 수 있다**("우리 가족 일정 중 보리 것").
3. **월 달력**: 날짜마다 **종류별 점**(넷 이상이면 `+`). **숫자를 안 적는다** — 한 칸이 좁아 무엇이 셋인지 알 수 없고, 색이면 병원인지 산책인지가 바로 보인다. 한 칸은 접근성에서 **하나의 노드**라 "10월 20일 · 일정 1건" 으로 읽힌다.
4. **그날 목록**: 시각 있는 것 먼저, 없는 것은 **"하루 종일"** 묶음. 한 줄은 `[아이콘] 제목 · 아이 · 담당 · 시각` + 완료 체크.
5. **`+` 시트**: 종류 → 제목 → 날짜/시각 → 아이 → 메모. **주인을 안 묻는다** — 가족 그룹이 있으면 `group`, 없으면 `dog` 이고 시트가 결과를 한 줄로 말한다("우리 가족이 함께 봅니다" / "이 일정은 나만 봅니다"). 가시성을 고르는 질문을 사용자에게 넘기지 않는다.
6. **빈 상태 둘**: 이 달에 아무것도 없으면 "아직 적어 둔 일정이 없어요 · 병원 예약부터 적어 볼까요" + `일정 적기`. **이 날만 비었으면** "10월 15일은 비어 있어요" — 둘을 같은 문구로 뭉치면 20일에 적어 둔 사람이 15일을 눌렀을 때 자기가 적은 것이 사라진 줄 안다.
7. **편집 충돌**: 서버가 409 를 주면 **최신 값으로 바꾸고** "○○님이 방금 고쳤어요" 를 말한다. 조용히 덮어쓰지 않는다.

**아직 없는 것**: 고치기 시트 · 담당자 고르기(#420).

1. **헤더**: 뒤로가기 + `산책 기록` + 우측 `저장`.
2. **장소·날짜 카드**(`_placeCard`): `어디를 걸었나요?` 장소 입력(place 아이콘, 힌트 "예: 서울숲, 한강공원, 동네 한 바퀴") + `날짜`(오늘 날짜 표시, 선택 UI는 아이콘만 — **미구현**).
   - 두 글자부터 **기기 안 카탈로그**에서 이름을 찾아 후보를 띄운다(#338, `PlaceCatalogRepository.search`). 검색어는 서버로 안 나간다. 고르면 초록 체크와 함께 `source`·`contentId` 가 붙고, 이름을 고치면 그 연결이 풀린다.
   - 고르지 않고 직접 적으면 "직접 적은 이름은 이 기록에만 남아요" — 그 기록엔 남지만 **"자주 가는 곳" 에는 안 들어간다**.
   - 지도에서 "여기서 산책 시작" 으로 왔으면 이름이 미리 채워져 있다. 아니면 **비어 있다**(예전엔 `오늘 산책` 이 박혀 있었다).
3. **거리·시간 스텝퍼 카드**(`_metricsCard`): `얼마나 걸었나요?` — 거리(±0.1km, 0~99) / 시간(±5분, 0~600) `−  값  +`.
4. **사진 카드**(`_photoCard`): `추가` 버튼(스낵바 "사진 첨부는 곧 지원돼요") + 더미 썸네일 2개. **미구현(플레이스홀더)**.
5. **메모 카드**(`_memoCard`): `오늘의 산책` 멀티라인 입력(4줄).
6. **저장하기 버튼**(하단, warm, pets 아이콘).

### 상호작용
| 요소 | 동작 |
| --- | --- |
| 스텝퍼 ± | `km` / `minutes` 증감(clamp) |
| 사진 추가 | 스낵바(미지원 안내) |
| 저장 / 저장하기 | `_save()` — `POST /api/walks`. 결과를 있는 그대로 말한다: 저장됨 / **"기록을 보관했어요 · 연결되면 올릴게요"** / 거절 사유 |

### 데이터
- 로컬 상태: `_place`(prefill 가능), `_memo`, `km`·`minutes`. **초안이 있으면 그 실측값에서 시작**하고, 없을 때만 손입력 기본값(2.0km / 30분)이다.
- 스텝퍼를 **만졌을 때만** 실측값을 덮는다. 안 만졌으면 초안의 초 단위 값을 그대로 보낸다 — 화면의 분 단위로 되돌리면 **1분 미만이 통째로 사라진다**(#145 에서 74초 산책이 `duration_s = 0` 으로 저장됐다).
- 초안은 전송을 **시도하기 전에** 먼저 큐에 들어간다 — 그 다음에 앱이 죽어도 남는다(#145).
