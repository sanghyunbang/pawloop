# 감정 여행 앱 — 리팩토링 핸드오프

감정 기반 장소 추천·기록 앱의 디자인 프로토타입입니다. 핵심 컨셉은
**"장소가 도와준 감정의 변화(A→B)"** 입니다 — 어떤 감정으로 도착해서
어떤 감정으로 떠났는지, 그리고 그 변화가 얼마나 자주 일어나는지를 데이터의
중심에 둡니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `감정 여행 앱.dc.html` | **메인 소스.** 디자인 컴포넌트(DC) 한 파일. 템플릿 + 로직(class Component) + 트윅(data-props)이 모두 들어 있습니다. |
| `support.js` | DC 런타임. `감정 여행 앱.dc.html`을 브라우저에서 열려면 같은 폴더에 있어야 합니다. |
| `감정 여행 앱 (단일파일).html` | 모든 의존성을 인라인한 **단일 실행 파일.** 더블클릭하면 바로 동작합니다. 동작 확인·공유용(수정은 메인 소스에서). |

## 실행 방법

- **빠른 확인**: `감정 여행 앱 (단일파일).html` 더블클릭.
- **편집/개발**: `감정 여행 앱.dc.html` 과 `support.js` 를 같은 폴더에 두고 로컬 서버로 서빙
  (예: `npx serve` 후 해당 파일 열기). file:// 로 직접 열면 일부 폰트/리소스가 막힐 수 있습니다.

## 화면 구성 (state.screen 기준)

- `today` — 오늘의 마음 선택 + 위로받기 진입
- `detail` → `analyzing` → `result` — 상세 입력(상황/맥락) → AI 분석 연출 → 맞춤 조언 + 집단 인사이트 + 장소 추천(A→B) + 👍/👎 피드백
- `explore` (`exView`: `map` / `list`) — 목적지 감정으로 필터하는 탐색. 핀 색 = 다녀온 뒤의 마음
- `placeDetail` — 장소별 변화 통계 + 그곳의 장소일기들
- `postDetail` — 장소일기 1건 + 스레드 댓글
- `create` — 기록 작성(도착했을 때 / 떠날 때 감정 + 공개 토글)
- `feed` — 내 기록 / 곁에(커뮤니티)
- `insight` — 마음의 흐름(감정 캔들 차트: 주간/오늘 OHLC) + 나를 바꿔준 곳 + 통계
- `me` / `edit` — 프로필 / 프로필 수정

## 데이터 모델 핵심

- `EMO[]` — 6개 감정(기쁨/슬픔/불안/분노/평온/설렘). 각 항목에 `c1`,`c2`(그라데이션) 보유.
- `mapData[]` — 장소. `{ from, to, lift, n, x, y, name, cat, dist, line }`
  - `from`→`to`: 대표 감정 변화, `lift`: 호전율(%), `n`: 표본 수.
- `communityData[]` — 장소일기. `{ nick, from, to, loc, story, base(리액션수), cmts[] }`
- 추천 매핑 `soothe = {0:5,1:0,2:4,3:4,4:4,5:5}` — 현재 감정 → 추천 목표 감정.

## 트윅(data-props)

테마(라일락/노을/수풀/자정 등), 색 선명도, 글래스 투명도, 카드 둥글기,
커뮤니티 탭 이름, 지도 핀 표시(도착 감정/개선율), 오라·핀 애니메이션 토글,
미리보기 시작 화면/감정 등.

## 실제 백엔드가 붙을 지점 (현재는 목업)

1. **상황 분류** — 자유 입력/선택을 일반화된 STATE로 (LLM)
2. **유사 사례 검색** — 비슷한 상황 임베딩 검색 → 집단 인사이트
3. **추천 정책** — 👍/👎 reward로 학습하는 컨텍스트 밴딧
4. **시계열 요약** — 감정 캔들/패턴 한 줄 요약
5. **지도** — 현재 stylized placeholder 맵. 실제 지도 SDK 연동 필요.

## 기술 메모

- 스타일은 전부 인라인(디자인 토큰 파일 없음). 폰트: Pretendard, 아이콘: Material Symbols Rounded.
- 로직은 순수 JS(타입스크립트/번들러 없음). `class Component extends DCLogic` 단일 클래스.
- 리팩토링 시 화면별 분리, 데이터 페칭 계층, 상태관리 도입을 권장.
